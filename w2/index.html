UPC Item Lookup with Optional LLM Summary

Jay C. Parangalan, CIT-82, Fall 2026

Instructor: Prof. Rio Waller

This project for CIT-82 Fall 2026 will be an online UPC merchandise lookup system with optional LLM support for product details. It will be mobile-targeted and take advantage of the user's smartphone camera to scan UPC labels and perform a lookup using a publicly-accessible item database service. If an optional API Key for an LLM is provided, it will be used to query for a basic description of the product.

Student Notes: The goal of this project is to make use of mobile-specifc resources that are made available via modern browsers, which I know is possible but I have not yet actually tried implementing. It will also perform API communications with an LLM which I have done only through Python scripts, and the translation to JavaScript should prove educational.

I do not yet know if access to a desktop or laptop webcam is possible (by default) through modern web browsers, so that functionality is yet to be determined. At worst, the webapp may simply indicate that no camera is detected.
